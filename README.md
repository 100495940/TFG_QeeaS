# TFG: Entropy as a Service (QeeaS) con ESP32-C6 y Zephyr RTOS

## 🛠️ Requisitos Previos en la Máquina Host

Antes de iniciar, la máquina anfitriona solo necesita tener instaladas las siguientes herramientas estándar de la industria:

1. **Docker Desktop** (Asegurarse de que esté abierto y corriendo).
2. **Visual Studio Code** con la extensión oficial **Dev Containers** instalada.
3. Conexión a Internet (para la primera descarga automatizada del entorno).
4. Además si la máquina en la que se ejecuta es Windows, se debe abrir el archivo conectar_usb_windows.bat previo a compilar el proyecto con los devcontainers. De esta manera entregamos los drivers de los puertos de windows a nuestro máquina Linux usada por el devcontainer.
